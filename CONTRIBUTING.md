# Contributing to Research AI

First off, thank you for considering contributing to Research AI! It's people like you that make Research AI such a great tool.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue providing as much information as possible, including steps to reproduce, what you expected to see, and what actually happened.

### Suggesting Enhancements
Enhancement suggestions are tracked as GitHub issues. When creating an enhancement suggestion, please provide a clear and detailed explanation of the feature.

### Pull Requests
1. Fork the repo and create your branch from `master`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code lints.
6. Issue that pull request!

## Code Style
* Please run `npm run lint` and `npm run format` (if available) before submitting your code.
* Follow the existing style of the codebase.

## Local Development
To set up your local development environment, please follow the steps outlined in the [README.md](README.md).

Thank you for contributing!
