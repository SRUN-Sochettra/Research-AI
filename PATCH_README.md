# SynapseDoc legal, privacy, and service-information patch

Drop this ZIP at the repository root and extract with overwrite enabled.

## Included

- Terms of Service
- Privacy Policy
- Acceptable Use Policy
- AI & Data Processing Notice
- Service Limits page sourced from existing constants
- Footer links to all disclosures
- Required age/Terms/Privacy confirmation during signup
- Upload-dialog disclosure for PDF-only and 10 MB maximum
- Public legal-contact environment variable
- Basic limit consistency test
- Launch review checklist and a detailed Agy verification prompt

## Important

The pages are tailored to the inspected repository but are not legal advice. The patch intentionally does **not** claim legal compliance, zero retention, complete deletion, or that Google never uses API data for improvement, because those statements depend on the production account, providers, regions, and live database configuration.

`NEXT_PUBLIC_LEGAL_EMAIL` must be configured before public launch.
